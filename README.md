# 별별 탐험대 · 유민이 웹 미리보기

유민이 학습 앱 '별별 탐험대' 화면을 브라우저에서 직접 눌러 보는 웹 미리보기입니다.
한글·수학·영어·그림 24강 커리큘럼, 한글 획순 애니메이션, 별 지도(14칸), 소원 쿠폰이 들어 있습니다.

- 열기: https://jroti0614-star.github.io/yumin-preview/
- 파일: `index.html` (외부 의존 없이 단독 실행되는 한 파일, Jua 폰트 내장)

## 지금 반영된 화면 (v5)

- 과목 카드(한글·수학·영어·그림)를 누르면 1~24강 목록 없이 **지금 진행 중인 강이 곧바로** 열립니다. 상단에는 `1 / 24강`처럼 강 번호만 표시되고, 강을 마치면 다음 강이 자동으로 이어집니다.
- 강을 골라 열거나 미리보기로 확인할 때는 🔒 보호자(PIN `1234`) 탭의 **강 바로 열기**를 씁니다.
- 한글 강은 **① 획순 배우기 → ② 문제 풀기 → ③ 따라쓰기** 순서로 한 페이지씩 넘어갑니다. 획순은 강에 들어가면 자동으로 한 번 재생되고, `다시 보기` 버튼 없이 획순 카드를 누르면 다시 그려 줍니다.

## 만든 방식

`work/byeol2/`(index.template.html · style.css · app.js · questions.js)를 `python3 work/byeol2/build.py`로 한 파일로 합쳐 `downloads/yumin-launcher-preview.html`을 만들고, 그 파일을 `index.html`로 올린 정적 페이지입니다. 서버나 빌드 과정 없이 GitHub Pages가 이 파일을 그대로 서빙합니다.

## 배포

GitHub Pages는 `gh-pages` 브랜치를 게시 소스로 쓰고 있습니다. 내용을 고칠 때는 `main`에 반영한 뒤 `gh-pages`에도 같은 파일을 올려야 사이트에 반영됩니다.

## 참고

- 아이폰 사파리에서 열면 홈 화면에 추가해 앱처럼 실행할 수 있습니다(`apple-mobile-web-app-capable`).
- 화면은 미리보기용이라 실제 앱의 저장·동기화 동작과는 다를 수 있습니다.
